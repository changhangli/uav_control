## 1. 为什么要改（不是换算法体系）

官方教程节点要接到本机老师控制栈（`swarm_msgs` + `uav_control` + mavros），话题/消息包名不同，必须先做适配。  
在此基础上，针对试飞中出现的：**高处码少、丢码硬降、指令总线被抢、机体系纠偏不明显**等问题，对策略做了增强。

控制链路不变：

```text
视觉 landmark → auto_land_by_pose → /uav1/uav_control_cmd → uav_control → mavros setpoint → PX4
```

## 3. 策略层：官方 vs 本机（当前版）

### 3.1 官方逻辑（简要）

- 看到码 → 基本一直用机体系 `XyzPosYawBody`，`z = -drop_height`（默认 0.15）边对准边降  
- 低空且水平偏差大时，把下降改成 `-0.05`  
- 水平+高度够近，或相对高度 &lt;0.2m → 最终垂直下降 + `EMERGENCY_KILL`  
- 丢码约 5s → 直接 `Land`  
- 等码超时约 10s → `Land`

### 3.2 本机当前逻辑（简要）

| 阶段 | 条件 | 行为 |
|------|------|------|
| 等待起飞 | 离地 &lt; `min_start_z`(0.5m) | **不发任何指令**（避免盖住起飞） |
| 稀疏对准 | 认出 ≥1 个码，但 &lt; `descend_min_markers`(2) | **只水平纠偏，高度锁定不降** |
| 纠偏+慢降 | ≥2 个码且水平未进门限 | 水平纠偏 + 慢降 |
| 正常下压 | ≥2 个码且水平已对准 | 下压；≥4 个码时步长更保守 |
| 最终阶段 | 精细条件 + 水平 OK + 高度近 | 垂直速度下降 → Kill（bench 跳过） |
| 丢码 | &gt;0.6s 无刷新 | 默认**保持高度**，不爬升、不盲 Land；贴得很近可直接落地 |

**真飞发令方式（重要）**：对准阶段改用与老师定点相同的 **`XyzPosYaw`（惯性系绝对坐标）**——  
把「板相对机体偏移」用当前 yaw 转到 ENU，再加到当前 `uav_state` 位置上发出。  
手持 `bench_mode` 仍用原来的 `XyzPosYawBody` 便于验 TX。

## 4. 主要新增 / 修改点列表

1. **话题与消息适配**（见上表）  
2. **`publish_control_cmd`**：统一发令 + `[TX phase]` 日志 + `subs` 计数  
3. **`auto_takeoff=false` 时重置 `last_time`**：避免一启动误判超时发 Land  
4. **`bench_mode`**：手持验链路，跳过等 `uav_state` / 跳过 Kill  
5. **码数参与决策**：`category_id` → `n_markers`；`align_min / descend_min / fine_min`  
6. **水平门限放宽**：`error_xy` 默认 0.10m（官方 0.05）  
7. **下降步长**：`drop_height` 默认 0.05（官方 0.15）  
8. **只降不升**：去掉丢码爬升，避免降↔升死循环  
9. **`min_start_z`**：地面/低高度不发令  
10. **惯性系纠偏**：真飞 `XyzPosYaw` + 高度锁定 `z_lock`  
11. **工程脚本**（`~/uav_worklog/scripts/`）：一键启停、录 bag、中文 tip 监视  

官方备份始终保留在 `official_upstream/`，可随时对比 `diff`。

## 5. Launch 关键默认参数（当前）

| 参数 | 默认 | 含义 |
|------|------|------|
| `auto_takeoff` | false（真飞建议） | 不自己起飞，等外部悬停 |
| `bench_mode` | false | 真飞关；手持验 TX 可开 |
| `error_xy` | 0.10 | 水平对准门限 (m) |
| `drop_height` | 0.05 | 下压步长相关 |
| `slow_drop` | 0.05 | 慢降 |
| `align_min_markers` | 1 | 几个码起开始纠偏 |
| `descend_min_markers` | 2 | 几个码起才允许下降 |
| `fine_min_markers` | 4 | 精细半步长 |
| `align_gain` | 1.0 | 水平纠偏增益 |
| `min_start_z` | 0.50 | 低于此高度不发令 |
| `land_on_lost_tag` | false | 丢码默认不 Land |
| `lost_tag_react` | 0.6 | 丢码反应时间 (s) |

## 6. 试飞结论摘要（供讨论）

- **指令能进 `uav_control`**：bag 中可见我们的 cmd；部分架次 setpoint 跟随明显（尤其惯性系后）。  
- **水平纠偏多数成功架有效**：视觉水平偏差缩小，但常与下降同时发生，肉眼像「竖直砸」。  
- **总线抢占**：老师定点/航点与降落节点同发 `/uav_control_cmd` 时，后到覆盖；手动改悬停点的架次不能当成「纯视觉纠偏」证据。  
- **未改老师 catkin**；崩溃类问题中至少有一例与动捕 EV yaw 异常相关，需与降落逻辑分开看。

更细的数据对照见：`~/uav_worklog/2026-08-07_水平纠偏与ULG对照.md`。
