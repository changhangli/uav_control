## 2026-08-07（周四）— 今日重点

### 目标

打通并验证「视觉 → lander → uav_control → 飞机」；完善策略；用 bag/ULG 证明水平纠偏。

### 完成

#### A. 工程与调试

- `start_land_stack.sh` / `stop_land_stack.sh`：视觉 + 录包 + tip 一键起停  
- `watch_land_status.py`：中文提示（指令是否发出 / 飞机是否照做），去掉难懂编号  
- `[TX phase]` 日志、`subs`、阶段名（如 `align_*` / `sparse_align`）  

#### B. 策略迭代（均在 `land_ws`，官方备份不动）

| 改动 | 目的 |
|------|------|
| 丢码默认爬升 → **只降不升 / 保高** | 避免降↔升死循环 |
| `drop_height` 0.15→0.05，`error_xy`→0.10 | 慢降、高处码少时对准门限放宽 |
| `n_markers` 门槛：1 码起纠偏，≥2 码才降 | 高处常见只有大码 |
| `min_start_z`：离地过低不发令 | 避免盖住起飞 / 误 Kill |
| 真飞改用 **`XyzPosYaw` 惯性系纠偏** | 缓解机体系 setpoint 水平几乎不动 |
| `bench_mode` 手持验 TX | 不真飞也能看指令链 |

#### C. 试飞结果（摘要）

1. **下午 16:24 左右**（`land_20260807_162421.bag`）  
   - 完整对准 → 下降 → 落地；设定点从悬停高度被改写并跟随  
   - 证明：**指令进入 uav_control 并可驱动飞机**（当时仍多为机体系）  

2. **傍晚～晚上**（对应 ULG 约 310/313/315/317）  
   - 多数成功架：视觉水平偏差缩小 + 有水平 setpoint/位移 → **纠偏有作用**  
   - 常 **边降边纠**，肉眼像竖直下落  
   - **315**：手动把悬停从约 1.1 调到 0.9 再挪点 → 总线上主要是定点 + `Land`，改完到落地**未对准码中心**（定点盖掉密发纠偏）  
   - **319**：动捕 EV yaw 异常翻转导致失控，**与纠偏逻辑分开讨论**  

3. 数据整理  
   - `2026-08-07_水平纠偏与ULG对照.md`  
   - Canvas：`~/.cursor/projects/home-uav/canvases/land-qr-align-20260807.canvas.tsx`  

### 遗留问题

1. 老师定点/航线与 lander **同话题抢占** → 测纠偏时需停掉其它发令节点  
2. 机体系阶段水平 setpoint 有时仍弱；惯性系已改，需更多架次复测  
3. 高处码数少（小码 12mm 远距离难识别）→ 依赖大码 + 分阶段策略  
4. FINAL 后 `EMERGENCY_KILL` 可能导致遥控器需重新拨杆解锁，需提前告知  

### 给老师演示建议

1. 看改动说明：`2026-08-07_相对官方auto_land改动说明.md`  
2. 看数据：`2026-08-07_水平纠偏与ULG对照.md`  
3. 现场：老师悬停并**停航线** → `start_land_stack.sh` → `tail -f ~/uav_worklog/run/land_tips.log`  
4. 成功指纹：`[TX ...]` 有 `XyzPosYaw(4)` 或对准阶段；tip 显示指令正常；飞机往板子方向挪
